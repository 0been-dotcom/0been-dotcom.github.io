## 💻 바로 쓰는 명령어

터미널에 그대로 복사해서 붙여넣으면 됩니다.

### 자주 쓰는 기본 명령어

**업데이트 확인 & 적용**
```bash
# 현재 버전 확인
hermes --version

# 최신 버전으로 업데이트
hermes update

# 업데이트 후 재확인
hermes --version
```

**세션 관리**
```bash
# 새 세션 시작
hermes

# 이전 대화 이어서
hermes -c

# 저장된 세션 재개
hermes -r "세션이름"
```

**세션 내 명령어** (대화 중 입력)
```bash
/compress    # 대화 압축 (느려졌을 때)
/usage       # 토큰 사용량 확인
/model       # 모델 변경
/new         # 새 세션
/stop        # 실행 중 작업 중단
```

## ❓ 자주 묻는 것들

**Q. 최신 소식 (2026-05-23)로 업데이트하면 기존 설정이 날아가나요?**

A. `hermes update` 명령은 설정 파일을 보존합니다. 기존 세션, 메모리, 스킬은 그대로 유지됩니다. 메이저 버전(v1.0 같은) 업그레이드가 아닌 이상 데이터 손실 없습니다.

**Q. 로컬 모델(Carnice, Ollama 등)도 이번 업데이트의 혜택을 받나요?**

A. 네. Hermes Agent 자체(에이전트 프레임워크)가 업데이트된 것이므로 로컬 모델 사용자도 동일하게 새 기능을 씁니다. 단, 일부 기능은 모델 능력에 따라 결과가 다를 수 있습니다.

**Q. Mac mini M4 / Apple Silicon에서 잘 돌아가나요?**

A. 잘 됩니다. llama.cpp 기반이라 Metal GPU 가속이 기본 지원됩니다. `-ngl 99` 플래그로 모든 레이어를 GPU에 올리면 빠릅니다. M4 Pro 48GB 환경에서 Carnice-V2-27B Q4 기준 안정적으로 동작합니다.

**Q. 업데이트 후 응답이 느려졌다면?**

A. 컨텍스트 캐시가 무효화됐을 수 있습니다. `/compress` 명령으로 대화를 압축하거나, 새 세션(`hermes`)을 시작해보세요. `-c 8192` 같이 컨텍스트 크기를 줄이는 것도 방법입니다.
